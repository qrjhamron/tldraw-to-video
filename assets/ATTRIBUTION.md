# Asset attribution

Do not assume online images are free to reuse. Every asset in this directory
carries explicit provenance in `manifest.json` (title, author, license,
source, sha256). Summary:

- `newton-portrait.jpg`: Isaac Newton, portrait by Godfrey Kneller (1689).
  Painting is public domain. File via Wikimedia Commons
  (`File:GodfreyKneller-IsaacNewton-1689.jpg`).
- `leibniz-portrait.jpg`: Gottfried Wilhelm Leibniz, portrait by Christoph
  Bernhard Francke (ca. 1695, Herzog Anton Ulrich Museum GG 558). Painting is
  public domain. File via Wikimedia Commons
  (`File:Christoph_Bernhard_Francke_-_Bildnis_des_Philosophen_Leibniz_(ca._1695).jpg`).
- `secant-tangent.svg`, `area-under-curve.svg`: authored diagrams for this
  repository (CC0-1.0).

Handwriting webfonts in `public/fonts/` (SIL OFL 1.1): Patrick Hand © Patrick
Wagesreiter, Kalam © Indian Type Foundry, Caveat © The Caveat Project Authors.
License texts: `public/fonts/OFL-*.txt`.
